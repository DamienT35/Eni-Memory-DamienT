Memory Game

Bienvenu sur Memory game try harder

Les règles sont simple.le Memory est un jeu d'association basé sur la reconnaissance visuelle
et la mémoire à court terme. Il se joue avec un jeu de cartes composé
de paires d'images identiques : les joueurs doivent mémoriser l'emplacement
des cartes pour retrouver les paires le plus rapidement possible.

Si vous voulez vous souvenir de votre score inscrivez-vous via le formulaire.
le jeu garde les 5 meilleurs scores.
Si vous voulez relancer une partie cliquez sur la barre d'espace.
