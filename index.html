Memory Game

Bienvenue sur Memory Game Try Harder.

Les règles sont simples : le Memory est un jeu d'association basé sur la mémoire visuelle.

Règles du jeu

  • Retournez deux cartes. Si les images sont identiques, le jeu laisse les cartes visibles.
  • Si les images sont différentes, les cartes se retournent faces cachées là où elles étaient.
  • La partie se termine lorsque toutes les cartes ont été assemblées par paires.

Si vous voulez enregistrer votre score, inscrivez-vous via le formulaire.
Le jeu conserve les 5 meilleurs scores.
Pour relancer une partie, appuyez sur la barre d'espace.
